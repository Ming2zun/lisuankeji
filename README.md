# 立算科技官网

这是立算科技的 GitHub Pages 静态官网，面向 ROS/ROS2、自动驾驶、机器人导航、感知算法、路径规划与无人系统开发服务。

## 页面地址

https://ming2zun.github.io/lisuankeji/

## 目录结构

- `index.html`：官网主页面，包含页面结构、样式和交互脚本。
- `assets/images/`：页面图片资源。
- `assets/vido/`：首页视频资源。
- `robots.txt`、`sitemap.xml`：搜索引擎抓取和索引辅助文件。

## 常用修改

- 联系邮箱、电话、地址：修改 `index.html` 里的 `siteConfig`，并同步页面中联系方式文本。
- 服务内容和项目案例：修改 `#services`、`#projects` 对应区域。
- SEO 标题和描述：修改 `<head>` 中的 `title`、`description`、Open Graph 和 JSON-LD 信息。

## 部署

仓库推送到 GitHub 后，GitHub Pages 会发布根目录的静态文件。
